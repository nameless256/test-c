Unicode 特殊码点（Special-Purpose Code Points）主要分布在以下几个范围：

## 1. **代理区（Surrogate Area）**
- `U+D800` – `U+DFFF`（共 2048 个码点）
- 用于 UTF-16 编码中的代理对
- **不能**作为独立字符使用

## 2. **非字符（Noncharacters）**
- `U+FDD0` – `U+FDEF`（共 32 个）
- `U+FFFE`、`U+FFFF`
- `U+1FFFE`、`U+1FFFF`
- `U+2FFFE`、`U+2FFFF`
- ... 一直到 `U+10FFFE`、`U+10FFFF`
- 共 **66 个**非字符，仅供内部使用，永不表示合法字符

## 3. **BOM / 零宽不换行空格（U+FEFF）**
- `U+FEFF` — **BOM（Byte Order Mark）** / 零宽不换行空格（ZWNBSP）
- 文件开头用于标识 UTF-16 字节序
- 在文本中间作为零宽不换行空格

## 4. **私用区（Private Use Area, PUA）**
- **PUA 基本区**：`U+E000` – `U+F8FF`（6400 个）
- **PUA 补充区 A**：`U+F0000` – `U+FFFFD`（65534 个）
- **PUA 补充区 B**：`U+100000` – `U+10FFFD`（65534 个）
- 共约 **13.7 万**个码点，供字体/应用自定义使用，Unicode 标准不赋予任何语义

## 5. **平面 0 中保留未分配的码点**
- `U+E0000` – `U+E007F` — **标签（Tags）** 区
- 部分用于语言标签（如 `U+E0061` 对应 `a`），现已弃用

## 汇总表

| 范围 | 用途 | 数量 |
|------|------|------|
| U+D800 – U+DFFF | UTF-16 代理对 | 2048 |
| U+FDD0 – U+FDEF | 非字符 | 32 |
| U+FFFE / U+FFFF | 非字符 | 2 |
| U+FEFF | BOM / ZWNBSP | 1 |
| U+E000 – U+F8FF | PUA 基本区 | 6400 |
| U+F0000 – U+FFFFD | PUA 补充区 A | 65534 |
| U+100000 – U+10FFFD | PUA 补充区 B | 65534 |
| 各平面末两位 FFFE/FFFF | 非字符 | 32 |

**关键点：** 这些特殊码点中，代理区和非字符在文本交换中不应出现；PUA 码点在不同字体/系统间不兼容，跨平台传输需谨慎。

好问题。非字符（Noncharacters）的用途很窄但很明确，**不是给普通人用的，而是给软件内部做协议标记用的**。

## 核心用途

### 1. **内部哨兵 / 标记值（Sentinel Values）**
这是最主要的使用场景。在 C/C++ 等语言中，用一个永远不会出现在合法文本中的值来标记「特殊状态」：

- **字符串结束标记**：某些底层实现用 `U+FFFF` 作为字符串内部缓冲区的结束符（类似 `'\0'` 但不会与真正的 null 混淆）
- **缓冲区占位符**：预分配数组时用非字符填充未使用的槽位，后续写入合法字符时覆盖
- **错误返回值**：API 返回「不是合法字符」时返回 `U+FFFE` 或 `U+FFFF`

### 2. **协议层面的分隔符**
在一些二进制协议或文件格式中：

- 用非字符分隔不同逻辑段，确保不会与文本内容冲突
- 例如 ICU（International Components for Unicode）内部用 `U+FFFF` 作为排序规则的边界标记

### 3. **内部查找失败标记**
- 字符串查找/替换算法中，用非字符表示「未找到」或「已处理过」
- 字符映射表（如大小写转换）中，用非字符表示「无映射」

### 4. **调试和测试**
- 测试 Unicode 实现的边界情况，验证程序是否正确处理非法码点
- 压力测试：确保程序不会崩溃或产生安全漏洞

## 实际例子

```c
// ICU 内部使用示例（简化）
#define U_SENTINEL 0xFFFF  // 非字符作为哨兵

// 字符串迭代器到达末尾时返回
UChar32 uiter_next(UText *ut) {
    if (pos >= end) return U_SENTINEL;
    return ut->chunk[pos++];
}
```

## 重要限制

| 不能做的事 | 原因 |
|-----------|------|
| ❌ 不能作为文本内容发送 | 违反 Unicode 标准，接收方可能拒绝或崩溃 |
| ❌ 不能存到数据库 | 索引、排序、搜索都可能出问题 |
| ❌ 不能用于 Web 页面 | 浏览器会忽略或显示为乱码 |
| ❌ 不能用于文件名 | 文件系统通常拒绝 |

## 一句话总结

> **非字符是 Unicode 留给软件实现的「内部便签纸」，不是给用户看的字符。**

就像编程中的 `-1` 或 `null` 常被用作错误/结束标记一样，非字符就是 Unicode 层面的这类标记——保证永远不会和真正的文本内容冲突。

Unicode 共规划了 **17 个平面（Planes）**，编号 0–16，每个平面有 65,536 个码点（`0x0000`–`0xFFFF`）。

## 平面总览

| 平面编号 | 范围 | 名称 | 简称 | 说明 |
|---------|------|------|------|------|
| **0** | U+0000 – U+FFFF | **基本多文种平面** | **BMP** | 最常用，绝大多数现代文字都在这里 |
| **1** | U+10000 – U+1FFFF | **补充多文种平面** | **SMP** | 古文字、表情符号、音乐符号等 |
| **2** | U+20000 – U+2FFFF | **补充表意文字平面** | **SIP** | 罕用/古汉字（CJK 扩展 B–I） |
| **3** | U+30000 – U+3FFFF | **第三表意文字平面** | **TIP** | CJK 扩展 G–H，部分已分配 |
| **4–13** | U+40000 – U+DFFFF | **未分配**（保留） | — | 留作未来扩展 |
| **14** | U+E0000 – U+EFFFF | **补充专用平面** | **SSP** | 标签字符、语言标签等 |
| **15** | U+F0000 – U+FFFFF | **私用区平面 A** | **SPUA-A** | 字体/应用自定义 |
| **16** | U+100000 – U+10FFFF | **私用区平面 B** | **SPUA-B** | 字体/应用自定义 |

## 各平面详细内容

### 平面 0 — BMP（基本多文种平面）
涵盖绝大多数日常使用的文字：

| 区块 | 范围 | 内容 |
|------|------|------|
| 基础拉丁 | U+0000–U+007F | ASCII（A-Z, 0-9, 标点） |
| 拉丁补充 | U+0080–U+00FF | 西欧重音字母 |
| 中日韩统一表意文字 | U+4E00–U+9FFF | 常用汉字（约 20,000+） |
| 韩文音节 | U+AC00–U+D7AF | 现代韩文 |
| 代理区 | U+D800–U+DFFF | UTF-16 代理对（非字符） |
| 私用区 | U+E000–U+F8FF | 字体自定义 |
| 兼容区 | U+F900–U+FAFF | CJK 兼容汉字 |

### 平面 1 — SMP（补充多文种平面）

| 重要区块 | 范围 | 内容 |
|---------|------|------|
| 表情符号 | U+1F600–U+1F64F | 😀😁😂... |
| 杂项符号和 pictograph | U+1F300–U+1F5FF | 🔥📦🎯 |
| 补充符号 | U+1F900–U+1F9FF | 🤖🤯🥳 |
| 古意大利文 | U+10300–U+1032F | 𐌀𐌁𐌂... |
| 线形文字 B | U+10000–U+100FF | 𐀀𐀁𐀂... |
| 音乐符号 | U+1D100–U+1D1FF | 𝄞𝄟𝄠... |
| 扑克牌 | U+1F0A0–U+1F0FF | 🂡🂢🂣... |

### 平面 2 — SIP（补充表意文字平面）
- **CJK 扩展 B**：U+20000–U+2A6DF（约 42,000 个罕用汉字）
- **CJK 扩展 C–F**：U+2A700–U+2CEAF
- 主要用于古籍、人名、地名中的生僻字

### 平面 3 — TIP（第三表意文字平面）
- **CJK 扩展 G–H**：U+30000–U+3134F
- 2020 年后新增的罕用汉字

### 平面 14 — SSP（补充专用平面）
- **标签字符**：U+E0000–U+E007F
- 用于语言标签（如 `U+E0061` = `a`），现已弃用

### 平面 15–16 — PUA（私用区）
- 共约 **13.7 万**个码点
- 字体厂商自定义字符（如公司内部符号、特殊图标字体）

## 一句话总结

| 平面 | 一句话 |
|------|--------|
| **BMP (0)** | 你每天都在用的——中英日韩文、数字、标点 |
| **SMP (1)** | 表情符号 😂 + 古文字 + 音乐符号 |
| **SIP (2)** | 你一辈子用不到几个的汉字 |
| **TIP (3)** | 更生僻的汉字 |
| **4–13** | 空着，留给未来 |
| **SSP (14)** | 废弃的语言标签 |
| **PUA (15–16)** | 字体厂商自留地 |
